# 贪吃笨狗 · Apple Snake

一款由单个 `index.html` 与静态资源组合而成的网页小游戏。小笨狗在苹果树下不断变长，同时要躲开哈气猫的追击。

## 在线试玩

<https://bengou.pages.dev>

## 玩法

- 苹果树会不停掉下苹果，吃掉可以**变长 2 节**
- 身体长到 **8 节**时，哈气猫会出现：它会先叼走地上的身体，再扑向你最容易咬到的部位
- 身体被咬到会从咬点**断成两截**，尾巴掉在地上；被咬到**头**就直接失败
- 吃到稀有的**金苹果**，7 秒内身体不会被咬断，反而能把哈气猫撞晕；用头撞它还能直接消灭
- 撞到墙、树或自己的身体只会**眩晕一下**，不会死

## 操作

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` / `W` `A` `S` `D` | 移动 |
| `P` | 暂停 |
| `R` | 重开 |

## 部署

纯静态、零外部依赖（最高分通过 `localStorage` 保存在浏览器本地）。将 `index.html` 与 `assert/` 目录一起托管到任意静态托管平台即可。
